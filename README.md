# Dev_Detective_Project


Dev Detective is a lightweight and responsive web application built using HTML, CSS, and JavaScript that allows users to search for any GitHub username and retrieve their public profile information in real-time using the GitHub REST API. The main objective of this project was to gain hands-on experience working with external APIs and dynamically updating the UI based on fetched data. When a valid username is entered, the app displays details such as the user’s name, bio, location, number of repositories, followers, following count, and other publicly available metadata. The interface is clean, intuitive, and includes a dark mode toggle for better user experience. Error handling is also integrated to show appropriate messages if the searched username does not exist. This project helped solidify concepts of asynchronous JavaScript (using fetch), DOM manipulation, conditional rendering, and responsive web design principles.
